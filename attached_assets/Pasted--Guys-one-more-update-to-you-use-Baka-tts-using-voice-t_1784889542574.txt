Introducing a new Baka mini-game: Roulette

How to play?

/roulette <amount> - Using this command, you will start a 2-minute joining window.

/join <amount> gems/coins - Using this command, you will join the Roulette game.

/bid <amount> - Using this command, you make a bid in Baka's DM.

What is the game's idea?

There will be (players-1) rounds in the game. In each round, you must make a bid such that your bid amount is greater than the lowest bid to be eligible to the next round, because in every round, the one player with the smallest bid will be eliminated.

Let's suppose you start a game with an amount of 1000 and there are 4 players; then there will be 3 rounds. In each round, the one player whose bid amount is smallest will be eliminated. Make sure you make a bid such that your bid amount is greater than the lowest bid.
